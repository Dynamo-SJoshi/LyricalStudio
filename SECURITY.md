# Security

If you find a security problem (for example a way to abuse the API routes, misuse the image proxy, or leak keys), please **don't open a public issue**. Report it privately through [GitHub's security advisories](https://github.com/arijit-debug/LyricalStudio/security/advisories/new) instead.

I'll reply as soon as I can and credit you in the fix unless you'd rather stay anonymous.
